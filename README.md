# Between the Slides

A simple web page for taking notes on lecture slides.

- Open a **PDF** and each page shows exactly as it is, with background graphics and side bands removed.
- Point at a spot on a page and press **+ Add note here**. The page opens up at the nearest gap between lines, and you type in your own font, size and colour.
- Notes sit in clear boxes. Drag a box's edges to resize it, or its ✥ handle to move it across the page (it snaps to the centre) or to another spot between lines, like a text box in Word.
- Select and copy text from the PDF pages.
- **PowerPoint (.pptx)** and **Word (.docx)** files open as text with their formatting, and you can type inside sentences too.
- Notes are saved automatically in your browser.
- **Download** your work as a **PDF** (pages with your notes, to read or print) or as a **notebook file** (one .html file you can open later on any device, or with Open file, to keep editing).

## Use it

Open it at **https://ylp-games.github.io/Between-the-lines/**, or open `index.html` in a browser. It is a single file with no build step.

Pushing to `main` publishes the site to GitHub Pages automatically (`.github/workflows/static.yml`).
